   - existing `styles/*.yaml` still validate under the updated schema;

     or ignored (locked value preserved) — assert the chosen safe behavior.
2. GREEN:
   - Add OPTIONAL `brand_lock` to `schemas/styles/playbook.schema.json` per CONTEXT D-01
     (do NOT add it to top-level `required`; keep back-compat). `check_schema` must pass.
   - Implement `apply_philosophy(base, overlay)` in `styles/playbook_loader.py` per D-02:
     overlay replaces LOOK sections (`motion`, `visual_language.composition`,
     `visual_language.texture`, pacing) only; anything under `brand_lock` and the locked
     palette/type it names is preserved; reject a locked-field override with a clear
     message; re-`validate_playbook(result)` before returning.
   - Add `styles/example-brand-lock.yaml` (valid, with a `brand_lock` block).
3. Verify tracer: `pytest tests/tools/test_brand_lock.py -q` GREEN; `python -c "from
