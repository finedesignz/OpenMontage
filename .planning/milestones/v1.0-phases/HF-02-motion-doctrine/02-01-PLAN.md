## Task 1 (tracer) — author the skill + wire ONE director, verify reference resolves

1. Write `skills/meta/motion-doctrine.md`, mirroring the shape/frontmatter of
   `skills/meta/reviewer.md` and `checkpoint-protocol.md` (read both first). Structure for
   **progressive disclosure**:
   - **Core (top):** the 11 Laws (genericized), the "cut this in half?" pre-ship test, the
     pre-flight checklist, the TL;DR one-liner. A director skill points at just this.
   - **Reference (below):** engine-neutral easing-by-purpose + stagger dictionary, pacing
     discipline, transition/motion vocabulary, anti-patterns.
   - Genericize: STRIP every crypto/Infinite/"stablecoin"/AIS/domain-specific example and
     any GSAP-only API detail that doesn't apply to OM's Remotion runtime. Laws stay
     universal; illustrate with neutral examples (a product demo, a report walkthrough).
   - Translate the two runtime-coupled laws to OM terms:
     * Law #11 ("timelines fill their slots / no-op anchor") → OM's **Remotion
       `calculateMetadata` +1s tail / black-frame-flash** gotcha (see project memory
       `remotion-render-gotchas.md`). State as "every composition's timeline must fill its
       declared duration; trim the exact target with ffmpeg -t".
     * "Velocity-matched easing at beat seams" → OM **screen-demo eased scrolls + overlay
       cursor easing**; keep the easing table as engine-neutral guidance.
   - ASCII-only punctuation (hyphens, straight quotes, three dots). No em/en dash, no smart
     quotes, no ellipsis char.
2. Wire the tracer director: add a short **"Consult `skills/meta/motion-doctrine.md`"**
   hook to `skills/pipelines/animated-explainer/scene-director.md` at the scene-planning
   step, naming which laws bite there (one-idea-per-beat, type-is-a-character,
   hold-the-hero, camera-never-sleeps). Single source of truth — do NOT copy doctrine body.
3. **Verify tracer:** `test -f skills/meta/motion-doctrine.md`; the file contains all 11
   Laws (grep the 11 law headings) + the pre-flight checklist; `grep -riE
   "infinite|stablecoin|\bAIS\b|crypto"` over the new skill returns ZERO; scene-director.md
   contains a resolvable `skills/meta/motion-doctrine.md` reference. Commit atomically.
